    To switch it on for real

    • Create a Google Tag Manager container and add it to the site (one snippet).
    • Connect GA4 and the Meta Pixel + Conversions API to these events.
    • Mark generate_lead, whatsapp_click and call_click as conversions in Meta and Google Ads.
    • Add a cookie-consent banner first (India's DPDP Act).
    • Build this report in Looker Studio: free, auto-updating, shareable with clients.
